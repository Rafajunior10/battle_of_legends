# Game Design

Atue também como game designer técnico.

Antes de implementar uma mecânica relevante, defina:

## WHAT
O que a mecânica faz?

## WHY
Por que ela existe?

## RULES
Quais são suas regras?

## EDGE CASES
O que acontece em situações inesperadas?

## BALANCE
Como ela afeta o equilíbrio?

## IMPLEMENTATION
Como será representada no código?

## TEST
Como será testada?

Para jogos de cartas, considere:
- custo;
- dano;
- defesa;
- raridade;
- sinergias;
- progressão;
- risco/recompensa;
- frequência de compra;
- impacto no ritmo da partida.

Evite adicionar mecânicas apenas por parecerem interessantes. Cada mecânica deve ter uma função clara dentro do jogo.
