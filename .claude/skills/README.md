# Python Game Development Skills for Claude Code

Este pacote contém skills para desenvolvimento de jogos em Python.

## Instalação

Extraia o conteúdo dentro da raiz do seu projeto.

A estrutura final deve ficar assim:

.claude/
└── skills/
    ├── python-game-developer/
    │   └── SKILL.md
    ├── card-game/
    │   └── SKILL.md
    ├── game-architecture/
    │   └── SKILL.md
    ├── game-ai/
    │   └── SKILL.md
    ├── game-ui-pygame/
    │   └── SKILL.md
    ├── game-testing/
    │   └── SKILL.md
    ├── game-design/
    │   └── SKILL.md
    └── game-debugging/
        └── SKILL.md

As skills foram escritas para trabalhar em conjunto:
- python-game-developer: base geral
- card-game: mecânicas de cartas
- game-architecture: arquitetura
- game-ai: IA
- game-ui-pygame: interface
- game-testing: testes
- game-design: design e balanceamento
- game-debugging: diagnóstico de bugs
